# PolySim OS — The 200 Multi-Solvers

**The tier above single solvers.** A *multi-solver* chains several individual solvers into one guided workflow that answers a real, end-to-end professional question. Numbers flow from one solver's output into the next, ending in a combined report/export.

**Why this is the logical next stage after 300 solvers**
- Single solvers answer *textbook* questions; multi-solvers answer *job* questions → far higher willingness to pay.
- Each is a packageable deliverable for the **Custom Solver Sets** offering (sell as themed packs).
- Defensible moat: impossible to assemble without first owning 300 real solvers.
- Natural home for premium tiers, an AI copilot that walks users through the workflow, and saved/shareable project files.
- Build target: `/multi/[slug]` chromeless multi-step pages that embed existing studios and pipe outputs forward. No new physics — pure orchestration.

Format: **Name** — the chained solvers / the question it answers.
