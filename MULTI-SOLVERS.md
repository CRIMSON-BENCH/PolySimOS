# PolySim OS — The 40 Multi-Solvers

**The next stage after 300 solvers.** A *multi-solver* chains several individual solvers into one guided workflow that answers a real, end-to-end professional question — "design this bridge," "plan this rocket mission," "build this portfolio." Numbers flow from one solver's output into the next.

**Why this is the logical next tier**
- Single solvers answer *textbook* questions; multi-solvers answer *job* questions → far higher willingness to pay.
- Perfect fit for the **Custom Solver Sets** offering — each is a packageable deliverable for a lab, firm, agency, or course.
- Defensible moat: nobody can assemble these without first owning 300 real solvers (we will).
- Natural home for premium tiers, AI copilot ("walk me through the workflow"), and saved/shareable project files.

### Build approach (when the 300 are done)
- A multi-solver is a **guided, multi-step page**: each step embeds an existing studio, pipes its key output into the next step's inputs, and ends with a combined report/export.
- Reuse the studio registry — no new physics, just orchestration + a results summary.
- Tag each as **Pro / Custom** for monetization; expose via `/multi/[slug]` and cross-link from every component solver.
- Ship them in themed packs (Structural Pack, Quant Pack, First-Responder Pack) that map directly to Custom Solver Set sales.
